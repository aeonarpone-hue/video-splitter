  3. app.netlify.com/drop သို့ သွားပြီး ထို Folder ကို ဆွဲထည့်လိုက်ရုံဖြင့် ကိုယ်ပိုင် Website Link ချက်ချင်း ရရှိပါမည်။
နည်းလမ်း ၂ — GitHub Pages (အမြဲတမ်း အခမဲ့)
  1. GitHub အကောင့်တွင် Repository အသစ်တစ်ခု ဆောက်ပါ။
